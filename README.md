Instagram Follower Tracker

A simple and lightweight tool for tracking changes in an Instagram follower list and identifying users who have unfollowed you.

📌 About the Project

This project was created with a simple goal: to make it easy to check who has stopped following you on Instagram without introducing unnecessary complexity.

The project is fully functional and has been designed to keep the code as clean, readable, and straightforward as possible. Rather than using a complicated architecture or adding unnecessary features, I decided to keep the project simple and focus on making the core functionality work reliably.

This is also a personal programming project, created to practice working with data, file management, automation, and processing Instagram follower information.

✨ Features

* Check your Instagram follower data
* Detect users who are no longer following you
* Compare follower lists
* Identify changes between different sets of data
* Simple input and output management
* Easy-to-understand project structure
* Lightweight and easy to run

🧩 Simple Structure

One of the main goals of this project is to avoid unnecessary complexity.

Input files and output files are kept in the same main project folder rather than being separated into multiple directories or handled through an overly sophisticated file structure.

This makes the project easier to understand, modify, and use, especially for anyone who wants to look at the code and understand how it works.

Keep it simple, clean, and functional.
